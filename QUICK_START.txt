 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

FRONTEND ERRORS:
  "npm: command not found"
    → Install Node.js from nodejs.org
    → Add node/npm to PATH
  
  "Missing dependencies"
    → Run: npm ci
  
  Port 3000 already in use
    → npm run dev -- --port 3001

BACKEND ERRORS:
  "php: command not found"
    → Install PHP from php.net or use Docker
    → Add PHP to PATH
  
  "Database connection failed"
    → Check DB_HOST, DB_USER, DB_PASSWORD in .env
    → Verify MySQL is running
    → Run migrations: php artisan migrate
  
  "CORS errors in browser"
    → Check FRONTEND_URL in .env
    → Ensure backend is running

DATABASE ERRORS:
  "Connection refused"
    → Start MySQL service
    → Check DB_HOST and DB_PORT
    → If using Docker: docker-compose up database

Best practice for local development:

   • Backend:   http://localhost:8000
   • Database:  http://localhost:8080 (phpMyAdmin)

5. Run commands in containers:
   $ docker-compose -f docker-compose.prod.yml exec backend php artisan migrate
   $ docker-compose -f docker-compose.prod.yml exec backend php artisan tinker
